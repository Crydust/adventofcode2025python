# Advent of Code 2025 in Python 3

Python solutions for [Advent of Code 2025](https://adventofcode.com/2025).

This project is a Python recreation based on the [Java solutions](https://github.com/Crydust/adventofcode2025) from the same author, now exploring Python for learning and distribution best practices.

## Setup and Usage

```shell
python -m venv .venv
.venv/Scripts/activate.bat
python -m pip install -e .
python -m pip install -e ."[dev]"
python -m ruff check
python -m pytest
python -m pip install build
python -m build
```
